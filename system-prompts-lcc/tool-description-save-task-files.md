Save files that a task produced to this computer. ${TOOL_DESCRIPTION_SAVE_TASK_FILES_VAR_0} Each file is saved in this session's task-files folder under that name, with a number added if the name is taken; nothing is overwritten. The person is asked to approve every call. The answer says where each file was saved, or why it was not.
