  again instead of starting a new one

 Once its requests are accepted again, send the agent a message (${DATA_TASK_NOTIFICATION_AGENT_CONTINUE_AFTER_REQUESTS_ACCEPTED_VAR_0}) to let it continue from where it stopped instead of starting a new agent.
